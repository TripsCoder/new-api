使用教程与条款

快速上手

  1. 选模型：在「创作台」的「视频生成」页签点选模型卡片，再选择生成方式（文生视频、图生视频、首尾帧、参考生视频等）；出图则切到「图片生成」页签。
  2. 写提示词：用自然语言描述画面内容、镜头运动与氛围。提示词越具体，效果越可控。
  3. 提交生成：确认预计费用后点「开始生成」，进度会在右侧任务列表实时刷新。

参考素材

  • 「首帧图 / 尾帧图 / 参考图 / 参考视频 / 参考音频」按生成方式决定是否可用，添加时支持粘贴公网地址或上传本地文件。
  • 上传的文件会先存到对象存储，再以链接形式提交给生成接口，下次可直接复用，不必重复上传。
  • 顺序即语义：提示词里的「图片1」「图片2」对应参考图列表的第 1、2 项，顺序可用卡片右上角的 ← → 调整。
  • 参考生视频必须提供参考素材：至少挂 1 个参考图 / 参考视频 / 参考音频，一个都没有时提交会被拦下（免得白扣一次费）。图片生成的参考图仍是可选的，不挂就是文生图。
  • 在提示词里输入 @ 可以直接引用资产库里的素材，自动挂到素材槽并插入正确的序号引用。

资产库

  • 上传到资产库的图片 / 视频 / 音频会长期保存在对象存储上，是所有生成任务的公共素材来源。
  • 支持改名、打标签、删除；删除时可选择是否同时删除云端文件。

消费与充值

  • 生成按模型、时长、清晰度计费，提交前会显示预计费用，生成失败会自动退回对应费用。
  • 「消费记录」一个菜单看全账目：页签「消费流水」列出每一笔扣费、退回与充值，页签「调用记录」列出每一次生成任务。
  • 全站以算力 ⚡计价（1 人民币 = 10 算力）；充多少用多少，没有任何折扣与门槛，也不再有注册礼 / 每日签到一类的赠送。充值记录按人民币 ¥ 计。
  • 算力不足时，可在钱包里用支付宝扫码充值，支付成功后算力自动到账。

常见问题

  • 任务一直排队？高峰期上游排队较久，可点「立即刷新」查看最新进度。
  • 生成失败扣费了？失败会自动原路退回，无需申请。
  • 视频生成总是提示失败？先核对两项：参考素材是否符合上文「参考素材」一节的规范（链接公网可直接打开、格式与数量不超限、首尾帧不与参考素材混用），提示词是否碰到审核红线（真人素材、侵权元素、暴露与暴力等）。确认都没问题就可以多次提交——上游同一个模型由多条线路共同承载，轮到要切换线路时也会失败，多试几次通常就能过。
  • 生成视频一直报「真人素材审核不通过」？上游渠道不固定，不同渠道的审核宽严有差异；同一条提示词多试几次、或换个时段再试，常常就能过。
  • 渠道视频提交半小时后返回失败？每天下午到晚上，渠道的可用存量可能不足：任务会在排队约半小时后以失败告终，恢复时间不确定。这类失败会自动原路退回扣费，建议换个时段（上午或次日）再提交。
  • 渠道视频下载不了？渠道视频生成成功后，归档会受网络影响：有时页面无法预览，但文件其实是可以下载的。如果在任务里找不到下载入口，可以联系客服帮忙取回。
  • 成片与图片保存期限？成片与图片生成后会自动存到云端，长期有效，本站不承诺永久保存，建议尽快将成片下载到本地留存，避免丢失。
  • 用户忘了密码？管理员可在「用户管理」里给该账号重置密码；重置后该账号所有已登录设备会立即下线，请把新密码私下发给用户。
