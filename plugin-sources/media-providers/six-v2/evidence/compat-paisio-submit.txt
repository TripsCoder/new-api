# 提交视频生成任务

## OpenAPI Specification

```yaml
openapi: 3.0.1
info:
  title: ''
  description: ''
  version: 1.0.0
paths:
  /v1/videos:
    post:
      summary: 提交视频生成任务
      deprecated: false
      description: |-
        ## 使用流程

        1. **提交任务** → 返回 `task_id`
        2. **轮询状态** `GET /v1/videos/{task_id}` → 每 3-5 秒
        3. **获取视频** status=completed 时 `video_url` 可直接下载（无需鉴权）

        ---

        ## 兼容路由

        以下路径功能完全相同，参数和响应格式一致：
        - `POST /v1/videos`（推荐）
        - `POST /v1/video/generations`（兼容格式）

        ---

        ## 统一参数

        所有视频模型使用完全相同的请求参数格式，后台自动处理各模型的格式差异。

        ---

        ## @引用语法

        在 prompt 中使用 @引用 来精确指代传入的素材：

        | 写法 | 对应字段 | 说明 |
        |------|----------|------|
        | `@Image1` 或 `@Img1` | image_url | 主参考图 |
        | `@Image2` 或 `@Img2` | extra_images[0] | 第1张额外图 |
        | `@Image3` 或 `@Img3` | extra_images[1] | 第2张额外图 |
        | `@Video1` 或 `@Vid1` | extra_videos[0] | 第1个参考视频 |
        | `@Audio1` 或 `@Aud1` | extra_audios[0] | 第1个参考音频 |

        引用不区分大小写。

        **示例：** `"@Image1 在街道上与@Image2 愉快的对话"` — 让主图中的人物和第一张额外图中的人物互动。

        ---

        ## 素材格式说明

        所有素材字段支持两种格式（可混用）：
        - **字符串格式**：`"https://example.com/file.png"`
        - **对象格式**：`{"url": "https://example.com/file.png"}`

        素材 URL 要求：
        - 必须为公网可访问的 http/https 链接
        - 图片：jpg / png / webp，建议 ≤ 10MB
        - 视频：mp4，建议 ≤ 100MB
        - 音频：mp3 / wav，建议 ≤ 20MB

        ---

        ## 计费规则

        - 按秒计费模型：预扣 duration × 单价，失败自动全额退款
        - 按次计费模型：提交时一次性扣费，失败自动全额退款
```
