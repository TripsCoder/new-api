              <h2>创建本站 API Key</h2>
            </div>
          </div>
          <p>登录控制台创建密钥。后续所有请求都使用同一个本站 API Key 认证。</p>

              <h3>创建 API Key</h3>
              <p>进入 API Keys 页面，新建密钥并复制。密钥只放本机环境变量或配置文件。</p>
            </article>
            <article class="docs-step">
              <h3>确认分组可用</h3>
              <p>如果返回模型不可用，通常是 Key 所属分组没有开启对应模型。</p>
            </article>
          </div>

        <section class="docs-section docs-anchor" id="text-to-video">
          <div class="sec-head">
            <div class="sec-ico">▷</div>
            <div>
              <div class="docs-kicker" style="margin:0">TEXT TO VIDEO</div>
              <h2>文生视频</h2>
            </div>
          </div>
          <p>只支持异步任务。提交后保存 <code>id</code> 或 <code>task_id</code>，使用同一把 API Key 轮询，不要重复提交。</p>
          <div class="tri">
            <article>
              <h3>认证与分组</h3>
              <p>使用对应分组的本站 API Key。任务只对创建它的 Key 可见。</p>
            </article>
            <article>
              <h3>异步任务</h3>
              <p>POST 立即返回任务 ID。收到后只轮询，不要再 POST 一次。</p>
            </article>
            <article>
              <h3>时长与分辨率</h3>
              <p>时长用 seconds 或 duration。分辨率写在模型名里，不要另传 size。</p>
            </article>
          </div>
          <h3>常用字段</h3>
          <ul>
            <li><code>model</code>：必须是价格页上的完整模型名</li>
            <li><code>prompt</code>：文本描述</li>
            <li><code>seconds</code> 或 <code>duration</code>：时长（秒），计费按成片秒数乘单价</li>
          </ul>
          <div class="code-panel">
            <div class="code-panel-head">
              <div class="titles">
                <p class="label">文生视频 · 创建任务</p>
                <p class="lang">BASH</p>
              </div>
              <button type="button" data-copy-pre>复制</button>
            </div>
            <pre>curl -sS https://artbox.top/v1/video/generations \
  -H "Authorization: Bearer sk-your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Artdance 2.5-720p",
    "prompt": "一只猫在阳光街道上走路，电影感运镜",
    "seconds": "5"
  }'</pre>
          </div>

            <li>图片必须是可公开访问的 HTTP(S) URL</li>
            <li><code>image_urls</code> 建议不超过 9 张（2.5 档可更多，见下一节）</li>
            <li>prompt 里可用 <code>@图片1</code> 对齐数组下标（从 1 起）</li>

        <section class="docs-section docs-anchor" id="refs">
          <div class="sec-head">
            <div class="sec-ico">◎</div>
            <div>
              <div class="docs-kicker" style="margin:0">REFERENCES</div>
              <h2>多参考与音频</h2>
            </div>
          </div>
          <p>Artdance 2.5 支持图片、视频、音频在同一任务中混合使用。素材必须是公网 URL；失败任务不会返回成片地址。</p>
          <ul>
            <li>2.5：图片最多 30、视频最多 10、音频最多 10</li>
            <li>2.0 / Mini / Fast：<code>image_urls</code>≤9、<code>video_urls</code>≤3、<code>audio_urls</code>≤3</li>
            <li>prompt 可用 <code>@图片N</code> / <code>@视频N</code> / <code>@音频N</code> 对齐数组下标</li>
            <li><code>generate_audio</code>：2.5 档可开原生同步音频</li>
            <li>2.5 最长 30 秒；2.0 / Fast / Mini 约 4–15 秒</li>
          </ul>

        <section class="docs-section docs-anchor" id="query">
          <div class="sec-head">
            <div class="sec-ico">↻</div>
            <div>
              <div class="docs-kicker" style="margin:0">QUERY</div>
              <h2>查询任务</h2>
            </div>
          </div>
          <p>创建响应里的 <code>id</code> 或 <code>task_id</code> 拿来轮询。状态直到 <code>completed</code> / <code>success</code> 或 <code>failed</code> / <code>error</code>。完成后读取成片地址，不要重复 POST。</p>
          <div class="code-pair">
          <div class="code-panel">
            <div class="code-panel-head">
              <div class="titles">
                <p class="label">查询单次</p>
                <p class="lang">BASH</p>
              </div>
              <button type="button" data-copy-pre>复制</button>
            </div>
            <pre>curl -sS https://artbox.top/v1/video/generations/{task_id} \
  -H "Authorization: Bearer sk-your-key"</pre>
          </div>
          <div class="code-panel">
            <div class="code-panel-head">
              <div class="titles">
                <p class="label">创建并轮询 · 完整脚本</p>
                <p class="lang">PYTHON</p>
              </div>
              <button type="button" data-copy-pre>复制</button>
            </div>
            <pre>import time, requests

BASE = "https://artbox.top/v1"
headers = {
    "Authorization": "Bearer sk-your-key",
    "Content-Type": "application/json",
}

created = requests.post(
    f"{BASE}/video/generations",
    headers=headers,
    json={
        "model": "Artdance 2.5-720p",
        "prompt": "一只猫在阳光街道上走路，电影感运镜",
        "seconds": "5",
    },
    timeout=60,
)
created.raise_for_status()
task = created.json()
task_id = task.get("id") or task.get("task_id")
print("task_id", task_id)

while True:
    r = requests.get(f"{BASE}/video/generations/{task_id}", headers=headers, timeout=60)
    r.raise_for_status()
    data = r.json()
    status = (data.get("status") or "").lower()
    print("status", status)
    if status in {"completed", "success", "failed", "error"}:
        print(data)
        break
    time.sleep(5)</pre>
          </div>

        <section class="docs-section docs-anchor" id="billing">
          <div class="sec-head">
            <div class="sec-ico">¥</div>
            <div>
              <div class="docs-kicker" style="margin:0">BILLING</div>
              <h2>计费</h2>
            </div>
          </div>
          <p>公开价格页展示 default 分组，单位是人民币 / 秒。实际扣费 = 成片秒数 × 模型单价，以控制台用量记录为准。</p>
          <ul>
            <li>模型名锁定分辨率，720p 和 1080p 不是同一个价</li>
            <li>失败任务是否扣费以账单记录为准，不要用预估秒数对账</li>
            <li>官渠视频上架后会走单独的价格分组，不和 default 的 Artdance 混在一栏</li>
          </ul>

        </section>

            <div class="sec-ico">✓</div>
            <div>
              <div class="docs-kicker" style="margin:0">VERIFY</div>
              <h2>验证接入是否成功</h2>
            </div>
          </div>
          <p>用 5 秒、720p 热推模型打一条文生，能拿到 task_id 并轮询到 completed，就算通了。</p>
          <ol>
            <li>创建 Key，确认分组看得到 <code>Artdance 2.5-720p</code></li>
            <li>POST 文生示例，响应里有 <code>id</code> 或 <code>task_id</code></li>
            <li>GET 轮询直到 completed，用量记录里能对上秒数和费用</li>
          </ol>

              <h2>接入前需要知道的事</h2>
            </div>
          </div>
          <div class="docs-faq">
            <details>
              <summary>平台主要支持哪些能力？</summary>
              <div class="answer">目前公开的是 Artdance 视频：文生、图生、多参考和音频。官渠视频会单独成 Tab。不要使用 /v1/chat/completions。</div>
            </details>

              <summary>Base URL 应该怎么填写？</summary>
              <div class="answer">填写 https://artbox.top/v1。创建和查询都在 /video/generations 下。</div>
            </details>
            <details>
              <summary>任务提交后怎么查结果？</summary>
              <div class="answer">POST 拿到 task_id，再 GET /v1/video/generations/{task_id}，直到 completed 或 failed。同一把 Key，不要换号查。</div>

              <summary>为什么不能改分辨率？</summary>
              <div class="answer">分辨率写在模型名里，例如 Artdance 2.5-720p。传 size / resolution 不会改档，也容易对不上价格。</div>
            </details>
            <details>
              <summary>价格和扣费在哪里查看？</summary>
              <div class="answer">公开价格页看 default 的元/秒。实际扣费以控制台用量记录为准。</div>
