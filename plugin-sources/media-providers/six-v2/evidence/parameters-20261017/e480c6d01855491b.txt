        <h2>模型与价格同步（只读目录接口）</h2>
        <p>用户工作台使用自己的 API Key，即可同步模型广场的模型名称、人民币售价和模型介绍。目录查询不扣费，原有生成权限保持不变。</p>
        <div class="endpoint"><span>GET</span><code>GET /v1/sub2api/model-catalog</code></div>
        <pre><code>GET https://lxmone.xyz/v1/sub2api/model-catalog
Authorization: Bearer YOUR_API_KEY</code></pre>
        <p>返回公开且已启用的模型，价格范围为公开默认售价（CNY），不代表专属折扣或该 Key 的全部可调用权限。需要筛选可调用模型时，可与 <code>GET /v1/models</code> 的结果取交集。</p>
        <p>建议每 30 秒同步一次。保存响应中的 <code>ETag</code>，后续发送 <code>If-None-Match</code>；未变化时返回 <code>304</code> 且无响应正文，继续使用本地缓存。接口变更不会影响原有生图、视频或语言模型调用。</p>
        <p><a href="/docs/model-catalog.html">查看完整接入说明、响应字段与调用示例</a> · <a href="/docs/model-catalog.md">Markdown 文档</a></p>
      </section>

        <div class="callout"><strong>gpt-image-2a 专用说明</strong><p>按成功生成的图片张数计费：1K（1024x1024）¥0.10/张，2K（2048x2048）¥0.15/张，原生 4K（3840x2160）¥0.20/张。不传 size 时明确请求 1024x1024 并按 1K 计费；不要使用 4096x4096。此模型图生图使用下面的 multipart image 文件字段，不使用后面的通用 JSON URL 编辑示例。</p><pre><button class="copy-button" type="button" data-copy-code>复制</button><code>curl <span data-api-base>https://lxmone.xyz/v1</span>/images/edits \
  -H "Authorization: Bearer sk-你的API密钥" \
  -F "model=gpt-image-2a" \
  -F "prompt=保持参考主体，改为电影感光影" \
  -F "image=@source.png;type=image/png" \

        <pre><button class="copy-button" type="button" data-copy-code>复制</button><code>curl <span data-api-base>https://lxmone.xyz/v1</span>/images/generations \
  -H "Authorization: Bearer sk-你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"<span data-selected-model>请选择模型</span>","prompt":"木桌上的红苹果，柔和棚拍光线","size":"1024x1024","n":1,"response_format":"url"}'</code></pre>
        <div class="callout"><strong>先区分两种操作</strong><p><code>/v1/images/generations</code> 是文生图；图生图、局部编辑和多图融合必须请求 <code>/v1/images/edits</code>。下面的 <code>images</code> 数组按顺序传入源图，最多 3 张；每张必须是公网可访问的图片直链（不是网页地址、登录页或临时预览页）。</p></div>
        <h3>图生图 / 多图编辑（JSON 公网 URL）</h3>
        <pre><button class="copy-button" type="button" data-copy-code>复制</button><code>curl <span data-api-base>https://lxmone.xyz/v1</span>/images/edits \
  -H "Authorization: Bearer sk-你的API密钥" \

  -d '{"model":"<span data-selected-model>gpt-image-2</span>","prompt":"保留第一张图的主体，将第二张图的配色和背景融合进去","images":["https://example.com/source-1.png","https://example.com/source-2.png"],"size":"1024x1024","n":1,"response_format":"url"}'</code></pre>
        <p class="hint">也可以把数组元素写成 <code>{"url":"https://example.com/source-1.png"}</code>；不要把多张图拼成一个字符串。若使用 Base64，请传完整的 <code>data:image/png;base64,...</code> Data URL。</p>
        <h3>图生图 / 本地多图上传（multipart）</h3>
        <pre><button class="copy-button" type="button" data-copy-code>复制</button><code>curl <span data-api-base>https://lxmone.xyz/v1</span>/images/edits \
  -H "Authorization: Bearer sk-你的API密钥" \
  -F "model=gpt-image-2" \
  -F "prompt=把两张参考图融合成一张统一风格的海报" \
  -F "image[]=@source-1.png;type=image/png" \
  -F "image[]=@source-2.png;type=image/png" \
  -F "n=1" \
  -F "size=1024x1024"</code></pre>
        <div class="callout"><strong>多图上传注意事项</strong><p>同一个字段名 <code>image[]</code> 重复上传即可保持图片顺序；也兼容重复的 <code>image</code> 字段。当前图生图最多 3 张源图，单张图片需使用 PNG、JPEG 或 WebP 等常见图片格式，并控制在接口允许的大小内。</p></div>
        <p class="hint">图生图请求不要发送到 <code>/v1/images/generations</code>；如果把本地文件路径写进 JSON，服务端无法读取，需改用上面的 multipart 上传。</p>
        <div class="callout"><strong>新增生图模型</strong><p><code>gpt-image-2.5-flare</code> ¥0.02/张；<code>gpt-image-2.5-sunburst</code> ¥0.03/张；<code>gpt-image-2.5-flare-官</code> 和 <code>gpt-image-2.5-sunburst-官</code> 均为 ¥0.30/张。带“官”的模型使用独立官渠，支持原生 1K、2K、4K 及全参；不带“官”的模型保持普通线路。按实际返回图片张数计费，支持文生图和参考图编辑；价格以模型广场当前配置为准。</p></div>
        <div class="callout"><strong>香蕉生图 2.1</strong><p>模型 ID：<code>nana-banana-2.1</code>，¥0.15/张，按实际返回图片张数计费。创建使用 <code>POST /v1/images/generations</code>；参考图编辑使用 <code>POST /v1/images/edits</code>（multipart/form-data）。在生图用途下选择“香蕉生图”查看模型；1K、2K、4K 均为相同单张价格，参数支持范围以模型说明为准。</p></div>
      
        <h3 id="async-images">异步生图（可选，普通同步接口不变）</h3>
        <p>异步接口使用相同的模型、参数、价格和本网站 API Key。提交请求返回任务 ID，再查询任务结果。编辑请求体与对应同步编辑接口保持一致：模型要求 multipart 时必须上传文件，不能改为 JSON。</p>
        <pre><code>POST /v1/images/generations/async   # JSON 参数与 /v1/images/generations 相同
POST /v1/images/edits/async         # 参数与 /v1/images/edits 相同
GET  /v1/images/tasks/{task_id}     # 使用提交任务的同一个 API Key</code></pre>
        <pre><button class="copy-button" type="button" data-copy-code>复制</button><code>curl https://lxmone.xyz/v1/images/generations/async \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2a","prompt":"一只小猫","size":"1024x1024","n":1}'
# HTTP 202: {"task_id":"imgtask_...","status":"processing","poll_url":"/v1/images/tasks/imgtask_..."}
curl https://lxmone.xyz/v1/images/tasks/imgtask_... \
  -H "Authorization: Bearer $OPENAI_API_KEY"</code></pre>
        <p>任务状态为 <code>processing</code>（处理中）、<code>completed</code>（完成）或 <code>failed</code>（失败）。建议每 3 秒查询一次；失败后停止轮询并读取 <code>error</code>。完成时 <code>image_url</code> 是第一张图，全部图片在 <code>result.data[].url</code>，不再返回 <code>b64_json</code>。</p>
        <p><strong>本地异步结果保留 12 小时：</strong>从结果保存时开始计时，返回本站签名临时链接，无需把 API Key 放进下载 URL。请在有效期内下载保存；到期链接失效，图片自动清理（每分钟检查），任务缓存也会过期。默认同步接口仍可使用，不会强制改为异步。</p>

      <section class="section" id="inline-reference">
        <h2>参考图与 base64 直传</h2>
        <p>参考图有两种写法：公网可访问的图片 URL，或把图片转成 base64 data URL 直接放进请求体（推荐）。如果请求报错提示<strong>获取不到图片</strong>，说明服务器拉不到你的图片地址（国内图床对海外服务器有限制），这时请改用 base64 直传：平台会把 base64 原样转发，不再依赖任何外部可访问地址。上面的协议示例里已经内置「<strong>图生视频（base64）</strong>」标签，选中即可复制可运行示例。</p>
        <div class="endpoint"><span>POST</span><code>POST /v1/videos</code></div>
        <p>用下面任意一种方式把本地图片编码成 data URL，再填进示例的参考图数组即可。</p>
        <pre><button class="copy-button" type="button" data-copy-code>复制</button><code># Linux
openssl base64 -A -in reference.jpg | sed 's|^|data:image/jpeg;base64,|'
# macOS
base64 -i reference.jpg | tr -d '\n' | sed 's|^|data:image/jpeg;base64,|'
# Windows PowerShell
"data:image/jpeg;base64," + [Convert]::ToBase64String([IO.File]::ReadAllBytes("reference.jpg"))</code></pre>
        <pre><button class="copy-button" type="button" data-copy-code>复制</button><code># Python：自动识别图片类型、检查体积，并写入 payload.json
python3 - &lt;&lt;'PY'
import base64, json, mimetypes, pathlib

path = pathlib.Path("reference.jpg")                              # 换成你的图片
media_type = mimetypes.guess_type(path.name)[0] or "image/jpeg"    # image/jpeg、image/png、image/webp
data_url = f"data:{media_type};base64,{base64.b64encode(path.read_bytes()).decode()}"

body_path = pathlib.Path("payload.json")
payload = json.loads(body_path.read_text(encoding="utf-8")) if body_path.exists() else {
    "model": "&lt;span data-selected-model&gt;请选择模型&lt;/span&gt;",
    "prompt": "镜头缓慢推进，人物回头看向镜头",
}
payload.setdefault("reference_images", []).append(data_url)       # 多张参考图就多次 append

print("data URL 长度：", len(data_url), "（单张上限 32MB）")
if len(data_url) &gt; 32 * 1024 * 1024:
    raise SystemExit("图片过大，请压缩后再试")
body_path.write_text(json.dumps(payload, ensure_ascii=False), encoding="utf-8")
PY</code></pre>
        <pre><button class="copy-button" type="button" data-copy-code>复制</button><code>curl -X POST "<span data-api-base>https://lxmone.xyz/v1</span>/videos" \
  -H "Authorization: Bearer sk-你的API密钥" \
  -H "Content-Type: application/json" \
  --data-binary @payload.json</code></pre>
        <p>字段名与 URL 方式完全一致：以协议 A/B 示例里的 <code>reference_images</code> 为准，<code>images</code>、<code>first_frame_image</code>、<code>last_frame_image</code> 同样接受，URL 与 data URL 可以在同一数组里混用。可运行的完整示例见上方两个协议里的「<strong>图生视频（base64）</strong>」标签。</p>
        <p><strong>Seedance 2.5 A 组四个模型例外：</strong><code>seedance2.5-480</code>、<code>seedance2.5-480s</code>、<code>seedance2.5-720</code>、<code>seedance2.5-720s</code> 使用 <code>assets</code> 数组；每项写 <code>{"category":"image","url":"https://…"}</code> 或 <code>{"category":"audio","url":"https://…"}</code>。本地文件则用 <code>data_base64</code> 传纯 base64 字符串，<strong>不要添加 <code>data:…;base64,</code> 前缀</strong>；不支持参考视频。传入参考图时，提示词须按顺序写 <code>@image1</code>、<code>@image2</code> 等；传入参考音频时须写 <code>@audio1</code> 等，否则请求会被拒绝。请求时长字段为 <code>duration</code>（4–25 秒），画幅字段为 <code>size</code>（例如 <code>16:9</code>），不传 <code>resolution</code>。请在上方选择对应模型后复制专属示例。</p>
        <p><strong>Grok 1.5-fast / 1.5（按次）例外：</strong>时长使用 <code>seconds</code>（4–15 秒），尺寸使用 <code>size</code>（例如 <code>1280x720</code>）；参考图须为公网 URL，格式为 <code>"reference_images":[{"url":"https://…","role":"reference_image"}]</code>，最多 7 张。不要照搬通用的 <code>duration_seconds</code>、<code>resolution</code> 或 base64 示例；请在协议 B 中选择具体 Grok 模型复制专属示例。</p>
        <div class="table-wrap"><table><thead><tr><th>项目</th><th>要求</th></tr></thead><tbody>
          <tr><td>格式</td><td>必须是 base64 data URL：<code>data:image/jpeg;base64,&lt;编码内容&gt;</code>；视频、音频参考同理（<code>data:video/mp4;base64,…</code>、<code>data:audio/mpeg;base64,…</code>）。</td></tr>
          <tr><td>不接受的写法</td><td>非 base64 的 data URL（如 <code>data:image/svg+xml,&lt;svg…&gt;</code>）、空内容、<code>data:text/plain;base64,…</code>。</td></tr>
          <tr><td>体积建议</td><td>单张 base64 不超过 32MB（约等于 24MB 原图），整体请求不超过 256MB；建议 JPEG/PNG、单张原图 ≤ 6MB。</td></tr>
        </tbody></table></div>
        <p>若参考图既不是公网 URL 也不是合规 base64，接口会直接返回 400 并说明原因，不会触发扣费。</p>
